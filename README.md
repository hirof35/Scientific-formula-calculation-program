# 重要科学式 計算プログラム

物理学・化学の基本となる6つの科学式を、コンソール上から対話形式で計算できるC++プログラムです。

## 計算できる科学式

| 番号 | 項目 | 計算式 | 入力単位 | 出力単位 |
| :--- | :--- | :--- | :--- | :--- |
| **1** | 運動エネルギー | $E = \frac{1}{2}mv^2$ | 質量 `kg`、速度 `m/s` | `J`（小数点以下4桁） |
| **2** | 位置エネルギー | $U = mgh$ | 質量 `kg`、高さ `m` | `J`（小数点以下4桁） |
| **3** | 熱量 | $Q = mc\Delta T$ | 質量 `kg`、比熱 `J/(kg・℃)`、温度変化 `℃` | `J`（小数点以下4桁） |
| **4** | オームの法則 | $V = IR$ | 電流 `A`、抵抗 `Ω` | `V`（小数点以下4桁） |
| **5** | ボイル=シャルルの法則 | $\frac{PV}{T} = \text{一定}$ | 圧力 `Pa`、体積 `m³`、温度 `℃`（内部で `K` に変換） | 一定値（小数点以下6桁） |
| **6** | 万有引力 | $F = G\frac{m_1 m_2}{r^2}$ | 質量1・質量2 `kg`、距離 `m` | `N`（指数表記・有効数字6桁相当） |

## 使用している物理定数

* **万有引力定数 ($G$):** `6.67430e-11` $[\text{N}\cdot\text{m}^2/\text{kg}^2]$
* **重力加速度 ($g$):** `9.80665` $[\text{m/s}^2]$
* **絶対零度オフセット:** `273.15`（摂氏 `℃` → ケルビン `K` 変換用）

## ビルドと実行方法

C++11以降に対応したコンパイラが必要です（例：`g++`）。

```bash
# コンパイル（ソースファイル名が main.cpp の場合）
g++ -std=c++17 -O2 main.cpp -o science_calc

# 実行
./science_calc
```

## 使い方

1. プログラムを起動すると計算メニューが表示されます。
2. 計算したい項目の番号（`1`～`6`）を入力し、画面の案内に従って各数値を入力します。
3. 計算結果が表示されたあと、再びメニューに戻ります。
4. `0` を入力するとプログラムを終了します。

### 入力チェック・仕様上の注意

* **万有引力の距離:** `0` 以下の値を入力するとエラーメッセージが表示され、計算をスキップします。
* **メニュー番号:** `0`～`6` 以外の数値を入力した場合は再入力を促すメッセージが表示されます。
* **数値入力:** 数値以外の文字列を入力した場合は標準入力（`cin`）の仕様上、ループが意図せず動作する可能性があります。数値を入力してください。

## 構成

* `main()`：メニュー制御、入出力処理、各計算関数の呼び出し
* `showMenu()`：選択可能な科学式一覧の表示
* 各計算関数：`kineticEnergy`、`potentialEnergy`、`heatQuantity`、`ohmsLaw`、`boyleCharlesLaw`、`gravitationalForce`
